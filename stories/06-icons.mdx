# Icons

Lucide, via `lucide-react`. It is set as `iconLibrary` in `components.json`, so vendored shadcn
components already arrive with Lucide imports resolved.

**Note the major version: `lucide-react@1.x`, not the familiar `0.x` line.** Snippets written against
`0.x` may reference icons that were renamed. The export list is large (6068 named exports at 1.31.0),
so verify a name resolves rather than trusting a remembered one.

## Stroke weight

`1.75` rather than Lucide's default `2`. At the sizes this kit uses, `2` reads heavy next to
monospace text, whose stems are comparatively light — the icon ends up louder than the label beside
it. `1.75` sits level with JetBrains Mono at the same optical size.

<ThemeSplit>

      <div key={w} className="text-center">
        <Search className="mx-auto size-6" strokeWidth={w} />
        <p className="mt-2 text-2xs text-muted-foreground">{w}</p>
      </div>
    ))}
  </div>
</ThemeSplit>

## Sizing

Icons size with Tailwind's `size-*` utilities and take `currentColor`, so they inherit text color
without a `color` prop. Three sizes cover nearly everything.

| Class      | Pixels | Pairs with                               |
| ---------- | ------ | ---------------------------------------- |
| `size-3.5` | 14px   | `text-xs`, dense table rows              |
| `size-4`   | 16px   | `text-sm`, buttons, inputs — the default |
| `size-5`   | 20px   | `text-base` and up, empty states         |

<ThemeSplit>
  <div className="flex items-center gap-6">
    {["size-3.5", "size-4", "size-5"].map((s) => (
      <span key={s} className="flex items-center gap-2 text-sm">
        <ArrowRight className={s} strokeWidth={1.75} />
        {s}
      </span>
    ))}
  </div>
</ThemeSplit>

## Accessibility

An icon is either decorative or it is the only label, and the two cases are handled differently.
Getting this wrong is the most common accessibility failure in an icon-heavy interface.

**Decorative** — the icon sits beside text that already says what it means. Hide it, so a screen
reader does not announce it twice:

```tsx
<button>
  <Search aria-hidden="true" className="size-4" strokeWidth={1.75} />
  Search
</button>
```

**Icon-only** — the icon _is_ the label. It needs an accessible name, and a `title` attribute is not
sufficient on its own:

```tsx
<button>
  <X aria-hidden="true" className="size-4" strokeWidth={1.75} />
  <span className="sr-only">Close</span>
</button>
```

`ThemeToggle` in `components/theme-toggle.tsx` is a working example of the second form.
