# Typography

Three faces, three jobs, no overlap.

| Face                   | Job                                                                                              | Reached via                         |
| ---------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------- |
| **JetBrains Mono**     | Everything. The default UI face — labels, buttons, inputs, headings, table data, numerals, code. | nothing; it is the document default |
| **Archivo**            | Long-form prose only. The one deliberate deviation from the anchor.                              | `prose-face`                        |
| **Archivo, condensed** | Oversized section figures only.                                                                  | `figure-condensed`                  |

Mono is the default because `--default-font-family` points at it in `@theme`, not because a utility
class is applied somewhere. That matters: a component that forgets to set a face still gets the
right one.

## The scale

Sizes keep Tailwind's familiar values, so `text-sm` still means roughly what it reads as. The
line-heights and tracking are retuned for monospace, which runs about 15% wider than a grotesk:
display steps take negative tracking to stop them sprawling, body steps take slightly more leading.

## Tracking

Uppercase monospace needs _positive_ tracking to stay readable — the counters close up otherwise.
Two tokens cover it, and they are the only places uppercase is sanctioned.

<ThemeSplit>
  <div>

      sample="Orbital period"
    />
    <TypeRow

    />
  </div>
</ThemeSplit>

## Numerals

`font-variant-numeric: tabular-nums` is set on `html`, so figures align everywhere rather than only
inside tables. This is an anchor requirement, not a convenience.

## Ligatures

JetBrains Mono ships code ligatures. `!=` collapsing into a single glyph is correct in a code block
and wrong in a button label, so `font-variant-ligatures: none` is set on `html` and re-enabled only
by the code components.

## Prose — the sanctioned deviation

The proportional face is available through `prose-face` and nowhere else. It bundles the face change
with its size and leading so the deviation stays in one place instead of scattering across
components.

<ThemeSplit>
  <div className="max-w-prose prose-face">
    <p>
      Long-form text sets in Archivo at a longer measure and looser leading than
      the UI chrome around it. This is the only context in the system where a
      proportional face appears, and the reason is readability at length rather
      than preference.
    </p>
  </div>
</ThemeSplit>

## Condensed figures

`figure-condensed` reaches Archivo's `wdth` axis at 62%. Its only job is oversized section
numbering — it is not a display face for headings, which stay in mono.

<ThemeSplit>
  <p className="figure-condensed text-7xl">01 02 03 04</p>
</ThemeSplit>
